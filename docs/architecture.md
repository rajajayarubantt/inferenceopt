# Architecture

```text
Browser (React SPA) --REST/SSE--> FastAPI (server/) --+
CLI (Typer, cli/) --------------------------------------+--> services/ --> core modules
Python API -------------------------------------------+                    |
                                                                            v
                                                     storage/ (SQLite)   runtimes (external processes)
```

## Layers

| Package | Responsibility |
|---|---|
| `schemas/` | Versioned Pydantic contracts shared by everything |
| `config/` | Config loading, per-user paths, secret redaction |
| `storage/` | SQLite (WAL) + Alembic migrations, applied automatically |
| `services/` | Application functions; the only thing the CLI and API call |
| `cli/` | Typer commands, thin wrappers over services |
| `server/` | FastAPI app, auth middleware, routes, static UI hosting |
| `_ui/` | Built web UI (generated by `ui/`, shipped in the wheel) |

Later phases add `hardware/`, `models/`, `runtimes/`, `benchmarks/`, `quality/`,
`optimizer/`, `experiments/`, `llm/`, `planner/`, `deployment/` and `security/`.

## UI build pipeline

`ui/` holds the React + TypeScript source. `pnpm build` writes static files to
`src/inferenceopt/_ui/`, which is gitignored but explicitly included in the wheel and
sdist. FastAPI serves those files and falls back to `index.html` for client-side routes.

The UI's API types are generated from FastAPI's OpenAPI schema:

```bash
uv run python scripts/gen_api_client.py   # writes ui/openapi.json + ui/src/api/schema.d.ts
```

CI fails if the committed client is out of date.
